# 푸드덕 병아리 🐥

탭 한 번으로 하는 장애물 피하기. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 화면을 탭하면 병아리가 푸드덕 날아오르고, 가만히 두면 떨어진다. 첫 탭에서 시작
- 사탕 기둥의 틈으로 지나가면 1점. 기둥이나 땅에 닿으면 끝 (천장은 닿아도 튕겨 내려올 뿐)
- 점수가 오를수록 틈이 좁아지고 조금씩 빨라지며, 12점부터는 위아래로 움직이는 기둥이 섞여 나온다
- 10점 동메달 · 25점 은메달 · 40점 금메달. 최고 점수는 `chickBest`
- 조작: 화면 탭 / PC는 스페이스·↑, P 일시정지, M 소리

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리는 `game.js`.
